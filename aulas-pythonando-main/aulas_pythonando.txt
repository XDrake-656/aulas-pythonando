               (Call satck)
                    Oque é :
                    Sempre que invocamos uma função, dados do seu escopo interno (como variáveis e parâmetros) precisam ser salvos em algum local. Além disso, também precisamos saber quando a função retorna um valor para que o programa continue a seguir o seu fluxo. Tudo isso é gerenciado pela Call Stack (pilha de chamada ou pilha de execução).

                    como funciona:
                    De forma simples e direta, quando meu programa está em execução e encontra uma chamada de função, ele pausa temporariamente o que estava fazendo e vai até o código interno da função para realizar sua execução. Após a execução, a função precisa saber como retornar o programa para o local onde ele parou antes da chamada para a execução. Então, após o retorno da função, o programa sabe como resumir o código partindo exatamente de onde a função retornou.

               (Funções recursivas)

                    * Funções recursivas são funções que chamam a si mesmas de maneira direta ou indireta durante a execução para resolver pedaços menores de um problema.

                    * Toda função recursiva precisa de dois componentes básicos para funcionar de forma correta:
                    • (Caso base): A condição de parada que encerra as chamadas e evita um loop infinito.
                    • (Passo recursivo): A chamada da função com um valor menor ou modificado que se aproxima do caso base.

                    exemplo :

                    def função(n):
                         bloco 1
                         return {#caso base}

                         return função(n - 1) {#caso recursivo}

                    * Vantagens: Deixa o código mais limpo e elegante para resolver problemas complexos como estruturas de árvores ou "algoritmos de busca".

                    * Cuidados: O uso incorreto ou a falta do caso base gera um erro de stack overflow (estouro de pilha) por esgotar a memória do computador.

                    * Consumo de Memória alto. A cada chamada consome espaço na memória (Call Stack) até atingir o caso base ou o limite.

                    * limite padrão de recursão (geralmente 1000 chamadas).
                         * Anão ser que seja modificado com o comando:
                         from sys import setrecursionlimit
                         setrecursionlimit(X) {x = valor do limir desejado} { CUIDADO OA USAR ESSE LIMITE EXISTE POR UM MOTIVO }


                    * diferente das estruturas for/while que repetem um bloco de código na mesma linha de execução.
                    A função recursiva cria uma nova cópia de si mesma na memória.

                    Quando escolher qual?
                    • Use for / while para 95% das tarefas do dia a dia (processar dados, ler arquivos, buscar itens em listas).
                    • Use Recursividade quando o problema for naturalmente divisível em subproblemas idênticos, especialmente ao lidar com estruturas ramificadas (como ler arquivos dentro de subpastas do computador ou analisar dados em formato JSON complexo).

                    exemplo :

                    def fatorial(n: int) -> int:
                    #caso base: quando ele chegar ao valor de 1 ele continua o codigo
                    if n == 1:
                         return 1 
                    #caso recursivo: faz um loop salvando na memoria todos os valores da fatorial ate que ele retorne o return e volte o codigo ate calcular todos os valores salvos
                    return n * fatorial(n - 1)

                    fat = fatorial(5)
                    print(fat)

                    * A sintaxe utiliza o símbolo "@" logo acima da definição da função que você deseja modificar.

                    * Iteráveis são reutilizáveis: Você pode rodar um laço for na mesma lista dezenas de vezes. Ela sempre reinicia do primeiro elemento.

               (Iterador)

                    * O objeto que faz o trabalho de percorrer. Ele guarda o estado de onde está e sabe como entregar o próximo item.

                    * Deve implementar __iter__() e __next__().

                    * O resultado de iter([1, 2, 3]), Geradores.

                    * Iteradores são descartáveis ("esgotáveis"): Uma vez que você percorreu um iterador até o final usando next(), ele fica vazio. Se tentar usá-lo de novo, ele continuará lançando StopIteration. Para ler os dados novamente, você precisa criar um novo iterador ou adicionar um valor de retorno padrão.

               Como eles trabalham juntos (O segredo do laço for):
                    Quando você escreve um como este:
                    lista = [10, 20, 30]
                    for item in lista:
                    print(item)

                    o Python faz exatamente o seguinte:
                    1. Pede o iterador: Ele passa o iterável (lista) para a função iter(). Ela ativa o método lista.__iter__(), que devolve um objeto iterador.
                    2. Consome os itens: O Python chama repetidamente a função next(iterador). Ela ativa o método __next__() para entregar um elemento por vez.
                    3. Para no final: Quando os dados acabam, o iterador lança uma exceção chamada StopIteration. O laço for entende isso como um sinal de parada e termina o código de forma limpa.


          (geradores)
               
               Se você tentar abrir um arquivo de 5 GB usando o método tradicional .readlines(), o Python tentará carregar todas as linhas para a memória RAM de uma vez, o que provavelmente fará o script quebrar por falta de memória (Out of Memory)
               Com geradores, o consumo de memória RAM permanece constante e baixíssimo (apenas alguns kilobytes), independentemente de o arquivo ter 10 MB ou 100 GB. Isso acontece porque o gerador lê e processa apenas uma linha por vez.
               * O gerenciamento de memória em Python ocorre de forma automática por meio de um heap privado gerido pelo próprio interpretador.

               O Heap Privado

               • Todos os objetos e estruturas de dados do Python ficam em um heap privado.
               • O programador não precisa alocar ou liberar espaço manualmente.
               • O gerenciador interno cuida de partes como cache, segmentação e pré-alocação


               Contagem de Referências (Reference Counting)

               • É o principal mecanismo do Python.
               • Cada objeto possui um contador que registra quantas variáveis ou estruturas apontam para ele.
               • Quando uma referência deixa de existir (por exemplo, a função termina ou a variável recebe outro valor) e o contador chega a zero, a memória do objeto é liberada de imediato.

               * pode se uasr o comando "asizeof" da biblioteca "pympler" para se verificar quantos bits de memoria um pragrama gasta
               print(asizeof(função))

               (yield e next)

                    (yield)

                         * A yield KeyWord transforma uma função em um gerador de funções.

                         * O código dentro da função não é executado na primeira chamada, mas sim dividido em etapas, uma etapa para cada `yield`, e cada etapa só é executada quando iterada.

                         * Ao contrário da return KeyWord que interrompe a execução da função, a yield KeyWord retorna o resultado obtido até o momento e continua para a próxima etapa.

                         * O valor retornado será uma lista de valores, um item para cada yield.

                    (next)

                         O next() função retorna o próximo item em um iterador.

                         Você pode adicionar um valor de retorno padrão, para retornar se o iterador tiver atingido seu fim.
                         ex.: print(next(function(x),"fim"))

                    exemplo de uso do yield e do next:
                         def dobro(lista):
                         for i in lista:
                              yield i * 2  {gera valores de um em um apenas quando interado}

                         y = dobro(range(2)) 
                         print(next(y,"fim")) {retorna o primeiro valor gerado: 0}
                         print(next(y,"fim")) {retorna o segundo valor gerado: 2}
                         print(next(y,"fim")) {retorna o valor padrão: fim}

               exeplo pratico do dia a dia para usar geradores para ler arquivos sem prencher o arquivo de memoria ram:

               def ler_linhas(nome_arquivo):
                    """Gerador que lê o arquivo linha por linha sob demanda."""
                    with open(nome_arquivo) as f:
                    for linha in f:
                         yield linha

               def filtrar_erros(linhas):
                    """Gerador analisa as linhas e procura erros"""
                    for linha in linhas:
                         if "CRITICAL" in linha:
                              yield linha

               def formatar_mensagem(linhas_filtradas):
                    """Gerador formata a mensagen"""
                    for linha in linhas_filtradas:
                         yield f"[LOG CRÍTICO] -> {linha.strip()}"

               # --- Uso do Gerador ---
               # 'mensagens_finais' é apenas um iterador pronto para começar.
               # Conectando o pipeline (Nenhum dado é processado ainda!)
               linhas = ler_linhas("sistema.log")
               erros = filtrar_erros(linhas)
               mensagens_finais = formatar_mensagem(erros)

               # O processamento real só acontece aqui, um item por vez dentro do laço
               for mensagem in mensagens_finais:
               print(mensagem)

          (arquivos)

               (open)

                    A função key para trabalhar com arquivos em Python é a função open().

                    O open() a função recebe dois parâmetros; nome do arquivo, e modo.

                    Existem quatro métodos (modos) diferentes para abrir um arquivo:
                    "r" - Leitura - Valor padrão. Abre um arquivo para leitura, erro se o arquivo não existir

                    "a" - Anexar - Abre um arquivo para anexando, cria o arquivo se ele não existir

                    "w" - Escrever - Abre um arquivo para escrita, cria o arquivo se ele não existir

                    "x" - Criar - Cria o arquivo especificado, retorna um erro se o arquivo existir

                    você pode especificar se o arquivo deve ser tratado como binário ou modo de texto:
                    "t" - Texto - Valor padrão. Modo de texto

                    "b" - Binário - Modo binário (por exemplo imagens)

                    sintaxe:
                    x = open("nome_do_arquivo", modo)

               (read)

                    O open() função retorna um objeto de arquivo, que possui um read() método para ler o conteúdo do arquivo:
                    f = open("exemplo.txt")
                    print(f.read())

               (close)
                    
                    * Sempre feche seus arquivos apos terminar oque estiver fazendo com ele
                    f = open("exemplo.txt")
                    print(f.readline())
                    f.close()     
               
               (with)
                    * with ja fecha os arquivos apos usalos assim não precisando usar o metodo close
                    Você também pode usar o with como declaração ao abrir um arquivo:
                    with open("exemplo.txt") as f:
                    print(f.read())

                    Por padrão o read() retorna o texto inteiro, mas você também pode especificar quantos caracteres deseja retornar:
                    with open("exemplo.txt") as f:
                    print(f.read(5))

                    Você pode retornar uma linha usando o readline() método:
                    with open("exemplo.txt") as f:
                    print(f.readline())

                    Ao percorrer as linhas do arquivo, você pode ler o arquivo inteiro, linha por linha:
                    with open("exemplo.txt") as f:
                    for x in f:
                    print(x)

               (write)
                    Para gravar em um arquivo existente, você deve adicionar um parâmetro ao abrir() função:
                    "a" - Anexar - anexará ao final do arquivo

                    "w" - Escrever - substituirá qualquer conteúdo existente
                    with open("exemplo.txt", "a") as f:
                    f.write("agora o arquivo tem um novo conteudo!")
                    
                    with open("exemplo.txt", "w") as f:
                    f.write("agora o arquivo foi apagado e tem um novo conteudo!")

     Orientação a objetos

          Python é uma linguagem orientada a objetos, permitindo que você estruture seu código usando classes e objetos para melhor organização e reutilização.

          * Fornece uma estrutura clara para os programas
          * Torna o código mais fácil de manter, reutilizar e depurar
          * Ajuda a manter seu código SECO (Não se repita)
          * Permite que você crie aplicativos reutilizáveis com menos código
          * Dica: O princípio DRY significa que você deve evitar escrever o mesmo código mais de uma vez. Mova código repetido para funções ou classes e reutilize-o.

          O que são Classes e Objetos?
          Classes e objetos são os dois conceitos centrais da programação orientada a objetos.

          Uma classe define como um objeto deve ser, e um objeto é criado com base nessa classe. Por exemplo:

          Classe	Objetos
          Fruta	Maçã, Banana, Manga
          Carro	Volvo, Audi, Toyota

          Quando você cria um objeto a partir de uma classe, ele herda todas as variáveis e funções definidas dentro dessa classe.

               (Class)

                    Quase tudo em Python é um objeto, com suas propriedades e métodos.
                    Uma classe é como um construtor de objetos ou um "blueprint" para criar objetos.

                    * PEP 8 nome das classes sempre com a primeiraletra de cada plavara em maiuscula ex.: MinhaClasse 

                    * Para criar uma classe, use a KeyWord class:
                    class MinhaClasse:
                         x = 5

               (__init__)

                    * Todas as classes possuem um método integrado chamado __init__(), que é sempre executado quando a classe está sendo iniciada.

                    * O __init__() O método é usado para atribuir valores às propriedades do objeto ou para executar operações necessárias quando o objeto está sendo criado.

                    * Usando __init__() facilita a criação de objetos com valores iniciais(pode definir valores padrão):

                    *O __init__() o método pode ter quantos parâmetros você precisar:
                    ex.:
                    class Person:
                         def __init__(self, name, age, cpf):
                              self.name = name
                              self.age = age
                              self.cpf = cpf
                    
                    * Sem o __init__() método, você precisaria definir propriedades manualmente para cada objeto:
                    ex.:
                    class Person:
                         pass

                    p1 = Person()
                    p1.name = "Tobias"
                    p1.age = 25
                    p1.cpf = 36257154

                    * Você pode adicionar novas propriedades a objetos existentes:
                    class Person:
                         def __init__(self, name):
                              self.name = name

                    p1 = Person("Tobias")

                    p1.age = 25
                    p1.city = "Oslo"

                    print(p1.name)
                    print(p1.age)
                    print(p1.city)
