		(listas)

usmos [] para escrever uma listas

* As listas são mutaveis

como criar uma lista:
lista = ["varavel", "variavel", "variavel"]
list(variavel) {cria uma lista da variavel}

como adicionar elementos na lista:

lista[x] = "variavel" {substitui uma variavel por outra sendo o valor de "x"}
lista.append("variavel"){adiciona uma variavel no final de uma lista}
lista.insert(x, "variavel"){como adicionar uma variavel em qualquer lugar de uma lista, "x" = posição da variavel}

como deletar listas e suas Variaveis:

del(lista) {deletar a lista do codigo}
del lista[x] {apagar uma variavl de uma lista na posição "x"}
lista.pop(X) {apagar a variavel na posição "x" se nao tiver um valor ele apaga a ultima variavel da lista}
lista.remove("variavel") {apagar a primeira variavel da lista e reorganiza os indixes da lista}
lista.clear() {limpa alista mas não a apaga}

*Caso tente apagar um item de uma lista e esse item não existir na lista o codigo dara um erro
para evitar use um if. Como asseguir:

if variavel in lista:
     lista.remove("varavel")

criando listas com range:

lista = list(range(x,x)) {cria uma lista uando os valores "x" e "x"}

colocando listas dentro de listas:

		(Dicionários)

usamos '{}' para identificar dicionarios

* Os dicionarios são mutaveis

criando dicionarios:

dicionario = dict()
dicionario = {"X":'variavel', "X": 25} {salva variaveis dentro de indices literarios ao inves de indices numericos}

adicionar indices e variaveis:

dicionario["X"] = "variavel" {cria o indice desejado e coloca sua variavel dentro no final do dicionario}

deletar variaveis em dicionarios:

del dicionario["X"] {apaga o elemento dentro do dicionario}

Buscar valores nos dicionarios:
dicionario.get("elemento", "default") {mostra a variavel dentro do elemento do dicionario}
					{caso não exista esse elento no dicionario ele mostra o valor default}


Valor Chave e Itens:

dicionario.values() {variaveis dentro dos elementos}
dicionario.keys() {elementos dos dicionarios}
dicionario.items() {mostra tanto os elementos quanto suas variaveis}

exemplo:
filme = {"titulo":"Star Wars", "Ano":"1977", "diretor":"George Lucas"}
for k, v in filme.items():
     print(f"O {k} é {v}") {retorna: O titulo é Star Wars
                                     O Ano é 1977
                                     O diretor é George Lucas}

pode se ter dicionario dentro de listas:

locadora = [{"titulo":"Star Wars", "Ano":"1977", "diretor":"George Lucas"}, {"titulo":"Matrix", "Ano":"1999", "diretor":"Wachowski"}]
print(locadora[0]["Ano"]) retotna: 1977
print(locadora[1]["titulo"]) retotna: Matrix

criando copias de dicionarios:

* diferente das listas que para criar uma copia de uma lista sem corelacionalos que se usava
o metodo [:]. Os dicionarios são um pouco diferentes se tentar da mesma forma que as lista
dara erro no codigo, tem que se uasar (.copy()):

lista.append(dicionario.copy()) {metodo correto sem dar erro}
